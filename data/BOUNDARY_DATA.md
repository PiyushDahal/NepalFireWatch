# Boundary data attribution

Nepal FireWatch uses **Level-3 local-level administrative boundaries** from
[Open Knowledge Nepal — localboundaries](https://github.com/openknowledgenp/localboundaries).

- Dataset: Nepal local-level boundaries
- License: **Creative Commons Attribution 4.0 International (CC BY 4.0)**
- License: https://creativecommons.org/licenses/by/4.0/
- Geometry is normalized to Nepal FireWatch's internal property schema; geographic
  coordinates are retained from the source GeoJSON.

Ward **numbers** used in alert text are resolved separately from the BIPAD API.
Nepal FireWatch does not currently draw ward polygons.
